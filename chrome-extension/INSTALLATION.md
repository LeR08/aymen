# 🚀 Installation rapide - Winner Finder

## ⚡ Installation en 3 étapes

### Étape 1 : Ouvrir Chrome Extensions
1. Ouvrez Google Chrome
2. Tapez `chrome://extensions/` dans la barre d'adresse
3. Appuyez sur Entrée

### Étape 2 : Activer le mode développeur
1. Activez le bouton **"Mode développeur"** en haut à droite
2. Trois nouveaux boutons apparaissent

### Étape 3 : Charger l'extension
1. Cliquez sur **"Charger l'extension non empaquetée"**
2. Naviguez jusqu'au dossier `chrome-extension`
3. Sélectionnez ce dossier et cliquez sur "Sélectionner"

## ✅ Vérification

L'extension est installée si vous voyez :
- ✅ "Produit Winner Finder – Algérie" dans la liste des extensions
- ✅ L'extension est activée (bouton bleu)
- ✅ Une icône dans la barre d'outils Chrome (vous devrez peut-être cliquer sur l'icône puzzle pour l'épingler)

## 🎯 Premier test

1. Allez sur https://www.facebook.com/ads/library/
2. Faites une recherche (ex: "beauté", "maison", etc.)
3. Cliquez sur l'icône Winner Finder
4. Le popup s'ouvre et détecte les annonces
5. Cliquez sur "Démarrer l'analyse"

## 📝 Note importante sur les icônes

⚠️ **Icônes manquantes**

Les fichiers d'icônes (PNG) ne sont pas inclus dans ce package. L'extension fonctionnera quand même, mais Chrome affichera une icône par défaut.

### Pour ajouter des icônes personnalisées :

1. Créez ou téléchargez 4 icônes PNG :
   - `icon16.png` (16x16 pixels)
   - `icon32.png` (32x32 pixels)
   - `icon48.png` (48x48 pixels)
   - `icon128.png` (128x128 pixels)

2. Placez-les dans le dossier `chrome-extension/icons/`

3. Dans Chrome Extensions, cliquez sur le bouton "Recharger" sous l'extension

### Recommandations pour les icônes :
- Utilisez un emoji 🔥 ou 💚 converti en PNG
- Ou créez un design simple avec Canva/Figma
- Ou utilisez un générateur en ligne (favicon-generator.org)
- Consultez `chrome-extension/icons/README.md` pour plus de détails

## 🐛 Problèmes courants

### L'extension ne se charge pas
- Vérifiez que vous avez sélectionné le bon dossier (`chrome-extension`, pas le dossier parent)
- Vérifiez que le fichier `manifest.json` est présent dans le dossier

### Erreur "Manifest file is missing or unreadable"
- Le dossier sélectionné ne contient pas de `manifest.json`
- Assurez-vous de sélectionner le dossier `chrome-extension`

### L'extension ne détecte pas les annonces
- Vérifiez que vous êtes bien sur `facebook.com/ads/library`
- Actualisez la page
- Attendez que les annonces se chargent

### Aucune icône visible
- Les icônes PNG ne sont pas créées (voir section ci-dessus)
- L'extension fonctionne quand même !
