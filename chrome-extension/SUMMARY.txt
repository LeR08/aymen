🚀 INSTALLATION
═══════════════════════════════════════════════════════════════════

1. Ouvrez Chrome : chrome://extensions/
2. Activez le "Mode développeur" (en haut à droite)
3. Cliquez sur "Charger l'extension non empaquetée"
4. Sélectionnez le dossier "chrome-extension"
5. L'extension est prête ! 🎉

Note : Les icônes PNG doivent être créées séparément
(consultez icons/README.md pour les instructions)

🎓 UTILISATION
═══════════════════════════════════════════════════════════════════

1. Allez sur https://www.facebook.com/ads/library/
2. Faites une recherche (ex: "beauté")
3. Cliquez sur l'icône Winner Finder
4. Choisissez le mode (Approfondi recommandé)
5. Cliquez sur "Démarrer l'analyse"
6. Consultez les résultats dans le dashboard
